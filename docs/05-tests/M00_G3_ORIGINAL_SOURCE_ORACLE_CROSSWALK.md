- Exactly eight original source renderings were read from the user's persistent Library, one per original AUD01, AUD01-DT, AUD02, AUD03, AUD04, AUD11, AUD12, AUD13 test suite. Their original scenario and expected oracle columns are included verbatim as **indexed extracted text**, not as rehashed original bytes.
- Table rows were joined by **exact test ID**, never by similarity of titles. This side-by-side format makes wrong semantics, omitted qualifiers and false translations reviewable in a single place.
- Original source artifact hashes from SOURCE_MANIFEST.md are registered, but the original bytes were **not re-materializable** in this session, so independent SHA-256 checking of these indexed text extracts was not performed here.
- The automated check covers **ID presence, unique source row, nonempty bilingual text** and basic shape. It cannot certify a translation's logical equivalence, distinguish a sample scenario from a formal product requirement, or mark a test VERIFIED.
- Numerical constants and policy states in source text can be **historical proposals**, not current ratifications. Later approved decisions govern. AUD13's proposed retry policy was not universally ratified.
- **Current counts:** 110 original table rows, 110 matching repository catalog rows, 0 catalog IDs missing in extracted source tables, 0 unexpected IDs, 0 parser/source warnings.
